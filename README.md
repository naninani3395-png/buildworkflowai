# BuildFlow AI

BuildFlow AI is an original, AI-powered construction and project management platform concept built as a modern full-stack portfolio project.

## Features
- Modern landing page
- Dashboard with KPI cards and charts
- AI-oriented operations summary
- Health API endpoint
- Responsive, dark UI

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
