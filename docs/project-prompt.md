# BuildFlow AI Project Prompt

Build an original full-stack SaaS called BuildFlow AI for construction and project operations using Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Recharts, Zustand, and Node.js-compatible APIs.

## Goals
- Create a polished landing page and dashboard experience inspired by modern SaaS products.
- Add modules for Projects, Clients, Employees, Inventory, Finance, Documents, Reports, and AI insights.
- Use a clean layered architecture with reusable UI components and realistic demo data.
- Make the app production-ready in structure, with API routes, responsive layouts, and documentation.

## Core Features
- Authentication screens
- Dashboard with KPI cards and charts
- Project management CRUD
- Client and employee modules
- Inventory and finance views
- AI assistant experience
- Dark theme and responsive design
